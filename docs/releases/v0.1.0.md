# Metra v0.1.0

Metra v0.1.0 is the first public, experimental pre-1.0 release of the
Rust-native local-first metadata toolkit and CLI.

## Highlights

- bounded signature-based readers for image, audio, document, media, RAW, XMP,
  and ICC containers;
- a typed Rust metadata model with stable namespaces, identifiers, warnings,
  schema-versioned structured output, and configurable parse limits;
- validated metadata seed creation for the documented format families;
- narrow `set`, `delete`, and `copy` writers with read-before-write checks,
  fixed-span preservation where applicable, output revalidation, and atomic
  replacement;
- deterministic recursive batches with bounded workers, streaming output,
  cooperative cancellation, `--validate`, `--compare`, and a public capability
  matrix;
- a real 49-second CLI walkthrough and a GitHub Pages project site.

## What's included

- source distribution on the `main` branch;
- MIT-licensed Rust workspace targeting Rust 1.95+;
- CLI formats: text, JSON, JSON Lines, CSV, TOML, and YAML;
- focused parser, writer, creator, registry, compatibility, and CLI tests.

## Installation / Download

No prebuilt binaries are attached to this release yet. Install from source:

```bash
git clone https://github.com/OthmaneBlial/Metra.git
cd Metra
cargo install --path .
```

The release source and repository are available at
<https://github.com/OthmaneBlial/Metra>.

## Known limitations

- Metra is not a drop-in ExifTool replacement and does not claim complete tag
  or format compatibility;
- many writers require existing storage, fixed packet length, or a supported
  layout and fail closed when those conditions are not met;
- proprietary RAW formats remain read-only outside the documented TIFF-like
  and CR3 seams;
- the differential corpus harness is opt-in and no corpus is distributed;
- Metra does not encode general image pixels, audio samples, or video tracks.

## Checksums

This release contains source only and has no attached platform binary to
checksum. GitHub's source archives are generated from the annotated repository
tag by GitHub.

## What's next
