# Metra v0.1.1

Metra v0.1.1 is a pre-1.0 quality and reproducibility release for the
Rust-native local-first metadata toolkit and CLI.

## Highlights

- checked-in synthetic corpus covering all 24 creatable fixture formats;
- SHA-256 manifest validation that remains byte-stable on Windows, macOS, and
  Linux;
- bounded streaming result buffering and deterministic corpus regression
  coverage;
- more tolerant semantic differential matching for temporal, ASCII, and GPS
  representations;
- initial public roadmap closed at 100%, with future work clearly separated.

## What's included

- source distribution on the `main` branch;
- MIT-licensed Rust workspace targeting Rust 1.95+;
- CLI output in text, JSON, JSON Lines, CSV, TOML, and YAML;
- real CLI demo and GitHub Pages project site;
- manual CI verification on Ubuntu, macOS, and Windows.

## Installation / Download

This release remains source-first. Install with Cargo:

```bash
git clone https://github.com/OthmaneBlial/Metra.git
cd Metra
cargo install --path . --locked
```

## Known limitations

Metra is not a drop-in ExifTool replacement. Format capabilities remain
bounded and are recorded in `compat/exiftool-compatibility.json`; proprietary
RAW writes, arbitrary media encoding, general pixel editing, and complete
MakerNote interpretation remain outside the current scope.

## Checksums

No platform binaries are attached. The repository corpus has its own checked-in
SHA-256 manifest at `fixtures/CORPUS_MANIFEST.json`.
